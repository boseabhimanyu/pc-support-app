# List of Roles

Super Admin
Admin
Head Technician
Technician
Receptionist
Customer

## Super Admin

### Purpose

Owns the system.

Responsibilities
Create Admin accounts.
Update Admin accounts.
Reset Admin passwords.
View everything.
Access all queues.
Access all jobs.
Access audit logs.

### Restrictions

Does not create technicians, receptionists, or customers.
Does not perform daily operational work.

## Admin

### Purpose

Runs the business.

Responsibilities
Create Receptionists.
Create Technicians.
Create Head Technicians.
Update staff.
Reset staff passwords.
Create customers
Manage customers.
Reset customers passwords.
Manage devices.
Create jobs.
View all queues.
View reports (future).
View audit logs.

## Head Technician

### Purpose

Runs the workshop.

Responsibilities
View Open Queue.
View Assigned Queue.
View In Progress Queue.
View Waiting Customer Queue.
Assign technicians.
Reassign jobs.
Resume jobs.
Review repair notes.
Update repair status.
Close jobs if required.

## Technician

### Purpose

Repair devices.

Responsibilities
View assigned jobs.
Update repair status.
Add repair notes.
Mark waiting for customer.
Resume repairs.
Close completed repairs.

## Receptionist

### Purpose

Customer-facing operations.

Responsibilities
Register customers.
Update customer details.
Register customer devices.
Create repair jobs.
Search customers.
Search devices.
Reset customer passwords.
View customer history.

## Customer

### Purpose

Track their own repairs.

Responsibilities
View profile.
Update profile.
View own devices.
View own jobs.
Track repair progress.
